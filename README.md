# Zombies Tracker & Calculator

A feature-packed desktop utility designed for Call of Duty Zombies players to calculate round stats, track powerups, manage GobbleGum packs, and calculate round/boss/bonus intervals.

## Features
* **Zombie Round Stats & Health Calculator:** Supports both Standard and Modern game modes with player count scaling, horde breakdown (24 zombies/horde), and cumulative stats.
* **SPH & Round Time Estimators:** Easily calculate seconds-per-horde and estimate individual or combined round times.
* **GobbleGum Pack & Tracker:** Interactive 5-slot pack setup and dynamic in-game tracker.
* **Powerup & Bonus/Boss Round Trackers:** Track active powerups, high-round dog/spider/monkey/excavator rounds, and ee/boss round milestones.
* **Dynamic Accent Color Picker:** Customize your UI accent color live on the fly.
* **Auto-Update Checker:** Automatically checks for new releases on startup.
